# Student Management System (Python)

## Overview
This is a console-based Student Management System developed using Python. The application performs CRUD (Create, Read, Update, Delete) operations and stores data permanently using JSON.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Save Data to JSON
- Load Data from JSON

## Technologies Used
- Python
- JSON
- File Handling

## Concepts Practiced
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- File Handling
- Exception Handling
- JSON

## How to Run

```bash
python student_management.py
```
